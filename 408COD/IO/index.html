中断执行过程¶

中断执行包括：中断响应（隐指令）、执行中断服务程序

条件

  1. CPU 处于“开中断”状态
  2. 至少有一个未被屏蔽的中断请求
  3. 当前指令刚执行完、进入中断周期

中断隐指令

  1. 关中断：否则保存现场、跳转时可能被打断，比如第一次中断的 PC、PSW 只保存了一个，则无法处理第一次中断。
  2. 保存 PC、PSW
  3. 选择某个中断源，跳转到对应的中断处理程序（设置新 PC、PSW）

中断向量、中断向量表、中断向量地址、中断向量表基地址

异常和中断¶

大多数外部设备都是可屏蔽中断，不可屏蔽和异常来自 CPU 本身

内部异常：硬故障中断、程序性异常

  1. 硬故障中断：硬件
  2. 程序性异常（软中断）：
    1. （故障、自陷、终止）三类
    2. 出现在前三个周期，出现时就响应，不用等到中断周期

外部设备和内部时钟是中断

DMA 控制方式¶

3种 DMA 方式

  1. CPU 停止法
  2. 周期挪用
  3. 交替分时访问法

DMA 后处理属于中断

2013 真题：“DMA 响应”是对请求总线的响应

2020 真题：“DMA 传送结束”是中断请求

例题：中断返回后，执行一条指令再响应中断，不是一个中断返回后立刻响应另一个，而是中间执行了一条指令
