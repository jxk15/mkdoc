第 4 章 网络层

  • 传输
  • 路由

非重点内容：移动 IP、组播、IPv6 协议

IP \(\ne\) 网络层

  • 网络层：IP、虚电路
  • TCP/IP 的网络层：IP

可靠传输服务以虚电路为实体；不可靠传输服务以 IP 协议为实体

IP 协议不可靠，因为设备性能高，即使重发，也比建立虚电路省时高效。

IP 数据报¶

  1. 版本：标识 IP 协议版本
  2. 首部长度：单位 4 B
  3. 总长度：单位 1 B，表示整个 IP 数据报的总长度，包括首部
  4. 生存时间 TTL：转发前→{减 1，若值为 0，丢弃}
  5. 协议：标识该 IP 数据报应该上交给哪个传输层协议。（6 代表 TCP，17 代表 UDP）
  6. 首部校验和：路由器的工作（接收方主机应该也校验）
  7. 标识(Identification)：确认分片后的数据报的原归属，主机的工作
  8. 分片标志(Flag)：DF(Don't Fragment)，MF(more Fragment)
  9. 片偏移：8 B

Tip

  1. 每经过一个路由器，TTL 改变，首部校验和因此改变。
    • 分片后，总长度、标志、片偏移也改变
  2. 分片后 IP 数据报的数据部分为 8 B 的整数倍。

分片¶

MTU：链路层帧能承载的最大数据量。即 IP 数据报的总长度上限。

发送方在传输层限制数据报大小，防止刚发出就分片。分片只发生在路由器上。

IPv4 地址规范¶

点分十进制记法

早期地址规范：网络号 + 主机号

  • A 类：1 ~ 126（没有 0、127）
  • B 类：128 ~ 191
  • C 类：192 ~ 223
  • D 类：多播地址；224~239
  • E 类：保留为今后使用；240~255

A 类网络号

  • 网络号全 0 的 IP 地址有特殊的用途
  • 网络号为 127，作为本地软件环回测试本主机的进程之间的通信

B 类网络号：\(2^{14}\)；最大主机数：\(2^{16} - 2\)

C 类网络号：\(2^{21}\)；最大主机数：\(2^{8} - 2\)

Info

曾经，B 类地址中的 128.0.0.0 和 C 类地址中的 192.0.0.0 都是规定不指派的。但现在这两个网络地址都已经可以指派了。[RFC 6890]

即第一个字节中为全 0

A、B、C：主机号全 0 和主机号全 1 的 IP 地址不可以分配给主机。

特殊的 IP 地址

  • 127.0.0.1 可以作为 IP 数据报的目的地址，理论上可以作为源地址
  • 255.255.255.255 和主机号全 1 的 IP 地址不能用作源 IP、只能作为目的 IP
  • 0.0.0.0 只能用作源 IP，不能用作目的 IP

路由器的互联端口、业务端口(1)

互联端口：必须同子网

业务端口（如 A 的 192.168.2.1/24 连接电脑，B 的 192.168.3.1/24 连接交换机）：必须属于不同子网

CIDR¶

无分类编址（Classless Inter-Domain Routing）：用在路由表中。

IP 地址：网络前缀、主机号

斜线记法（CIDR 记法）：即在 IP 地址后加上斜线，斜线后面是网络前缀所占的位数。

128.14.32.0/20 可以写成 128.14.32/20

报文交换、分组交换¶

报文交换：在交换结点采用存储转发的传输方式；对报文大小没有限制，要求网络结点有较大的缓存空间。（主要使用在早期的电报通信网中，现在较少使用，通常被较先进的分组交换所取代）

分组交换：存储转发；适应不同的 MTU。分为数据报和虚电路两种方式。

虚电路

  • 建立连接：根据源 IP、目的 IP 建立连接、VCID 号
  • 数据传送：使用 VCID 号
  • 连接拆除

路由协议¶

  1. 路由信息协议 RIP：若局域网规模偏小，则使用该协议建立路由表
  2. 开放最短路径优先协议 OSPF：若局域网规模偏大，
  3. 边界网关协议 BGP：两个网际之间的交互路由，
