第 1 章 绪论

IP \(\ne\) 网络层；网络层：IP、虚电路。

接口（访问服务点SAP）：上层使用下层服务的入口。

服务：下层为相邻上层提供的功能调用

  • 面向连接服务（建立连接、传输数据、释放连接）和无连接服务（直接发送数据）
  • 可靠服务和不可靠服务
  • 有应答服务和无应答服务

可靠传输：

  1. 缓存：丢失时重发
  2. 编号：重复、乱序、丢失

分层思想¶

网络层¶

网络层的目的：提供从源主机到目的主机，以数据报为单位的尽力交付（对于丢失、失序、出现bit错误等问题不做处理）的通信协议。传输单位：IP 数据报或网络层数据报。

  • IP 功能（提供网络层的数据传输服务）：不面向连接（IPv4 协议、IPv6 协议）、面向连接（虚电路）
  • 路由服务（生成和建立路由表）：RIP、OSPF、BGP

网络层设备

  • 路由器：网络层使用的中间设备
  • 网关：网络层及以上使用的中间设备；可以使用传输层协议，比如运行 NAT；（考试中不区分

数据链路层¶

数据链路层的目的：提供相邻两节点之间，以帧为单位的数据通信任务。传输单位：数据帧。

  • 数据可靠传输
    • 有确认：802.11 无线传输协议
    • 有确认、无连接：停止等待协议、后退 N 帧协议、选择重传协议
  • 数据无差错传输
    • 无确认、无连接：以太网协议

Note

网卡向内存传输数据时，可能出现错误，但不做处理。就是默认把这部分概率极低的错误当作在链路上的错误。

物理层¶

物理层的目的：让信号通过编码或调制，实现其在信道上进行传输。

  • 数字信号编码为数字信号：1归零编码、2非归零编码、3反向编码、4曼彻斯特编码、5差分曼彻斯特编码
  • ⭐数字信号调制为模拟信号：正交振幅调制（QAM）
  • 模拟信号编码为数字信号：采样定理
  • 模拟信号调制为模拟信号（×

Note

入户箱和光猫：光纤、模拟信号

光猫和路由器、路由器和主机之间：网线、数字信号

往返时间 RTT¶

信道利用率¶

用来表示某信道有百分之几的时间是被利用的（有数据通过）

信道利用率并不是越高越好。信道利用率高也意味着网络的拥挤程度更高，拥挤会造成数据丢失和延迟增加等情况。

丢包率¶

分组丢失主要有两种情况：

  1. 分组在传输过程中出现误码，被结点丢弃
  2. 分组到达一台队列已满的节点时被丢弃。在通信量较大时就可能造成网络拥塞。

边缘、核心、接入网

四大延迟：结点处理时延（nodal processing delay）、排队时延（queuing delay）、传输（发送）时延（transmission delay）和传播时延（propagation delay）

计算机网络是联网的计算机所构成的系统

  • 节点：主机节点、数据交换节点
  • 链路：接入网、骨干链路
  • 协议：对等层的实体在通信的过程当中应该遵守的规则。语法、语义、时序
